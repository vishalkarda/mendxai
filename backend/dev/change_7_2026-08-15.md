## Kernel / ipykernel guidance

1. Locate the virtual environment created by `uv` (commonly `backend/.venv` or `.venv` at project root). Example:

```bash
ls -la backend/.venv || ls -la backend/venv || ls -la backend/.venv/bin
```

2. Activate the venv and install `ipykernel` inside it (if not already installed):

```bash
# macOS / Linux
source backend/.venv/bin/activate
pip install ipykernel

# register kernel for VS Code/Jupyter
python -m ipykernel install --user --name mendxai-backend --display-name "mendxai-backend (.venv)"

# deactivate when done
deactivate
```

3. In VS Code: Command Palette -> `Python: Select Interpreter` -> choose `mendxai-backend (.venv)` interpreter. Then in the Notebook UI choose Kernel -> `mendxai-backend (.venv)`.

4. If VS Code still prompts to install `ipykernel`, open an integrated terminal, activate the chosen interpreter, and run the `python -m ipykernel install ...` command manually; then reload the window.

5. If you prefer not to register a kernel globally, you can run the notebook server with the venv active:

```bash
source backend/.venv/bin/activate
jupyter lab
```
